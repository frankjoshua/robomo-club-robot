# Personal robot models

This is the home for Josh's personal TX2 robot's Blender scenes, CAD source,
exported meshes and preview renders. **No personal Blender scene has been
created or imported yet.**

Use [personal photos](../images/README.md) and the [personal specs](../specs.md)
when creating one. The 14-inch circular chassis and its sensor mounting are
separate from the club's wheelchair-base model. Record estimated dimensions
separately from measurements, especially the unverified laser height.

The [runtime TX2 URDF](../../../config/tx2.urdf) currently provides the sensor
transforms. It is a runtime configuration file, not a personal photo-based
Blender model. The club scene is under [club/models/](../../club/models/README.md).
