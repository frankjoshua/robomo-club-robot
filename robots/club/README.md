# Robomo club robot

The club's Jetson Nano robot uses a salvaged Little Rascal wheelchair base,
a mast, tray-mounted electronics, and an Acer monitor. Its hostname is
`robmo-club-robot.local`.

- [Specifications and evidence](specs.md)
- [Network and operating notes](operations.md)
- [Original photos](images/README.md)
- [Blender scene, build script and rendered previews](models/README.md)
- [Wiring and hardware documents](docs/README.md)
- [Configuration index](config/README.md)

The [personal TX2 robot](../personal/README.md) has a different chassis,
calibration and power arrangement. The September 2026 club Blender model is a
photo reconstruction, not a source of measured navigation geometry.
